# Tutorial-App
MERN Stack
Developed a full-stack e-learning platform built with the MERN stack, supporting two user roles: Admin (Tutor) and User (Student). Admins have access to a dedicated dashboard where they can create, update, and delete courses and lectures, manage users, view course and payment details, and access any course content without enrolment. Students can sign up, browse available courses, make payments through an integrated Razor pay gateway, and access only the courses they’ve enrolled in. The application features secure JWT-based authentication, Multer integration for media uploads, and a responsive frontend using React and React Router for seamless navigation. This project demonstrates strong skills in building scalable, secure, and user-focused web applications with a clear separation of concerns and role-based access control.
